# StitchProof

A local tech editor for crochet patterns. A small open-weight model, fine-tuned on Tinker, translates each written row of a pattern into a precise stitch program. Plain code then simulates the stitch counts row by row and flags every place where the stated count does not match what the instructions actually produce.

Work in progress. See [SPEC.md](SPEC.md).
